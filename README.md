# ИИ-ассистент: анализ судебных документов (хакатон «ИИ-ассистенты для энергетики», трек №2)

Конвейер распознавания и извлечения данных из PDF-сканов судебных актов (арбитраж):
**PDF → OCR → структурированный JSON → Excel** — полностью локально, на open-source стеке.

## Возможности
- OCR сканов: **qwen3-vl:8b** (vision-модель Ollama) с автоматическим **fallback на PaddleOCR** при пустом/коротком результате;
- извлечение полей: суд, № дела, взыскатель, должник (ИНН, адрес), суммы (долг/неустойка/госпошлина/итого) — **qwen2.5:14b** → строгий JSON;
- составной ключ документа: **№ дела + суд + адрес должника** (№ дела сам по себе не уникален);
- экспорт сводки в Excel для юриста.

## Быстрый старт (5 шагов)

```bash
# 1. Python 3.13+ и виртуальное окружение
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS

# 2. Зависимости (внимание: paddlepaddle зафиксирован на 3.2.2 — 3.3.1 сломан на Windows)
pip install -r requirements.txt

# 3. Модели Ollama (скачаются один раз, ~15 ГБ суммарно)
ollama pull qwen3-vl:8b
ollama pull qwen2.5:14b

# 4. Обработка папки с PDF
python pipeline.py "C:\path\to\pdfs"

# 5. Excel-сводка
python excel_export.py --input СВОДКА_результатов.json --output документы_судов.xlsx
```

Результаты пишутся рядом с PDF: `*_text.txt` (распознанный текст), `*_result.json` (поля),
`СВОДКА_результатов.json` (все дела).

## Конфигурация (.env, опционально)

```env
OLLAMA_URL=http://127.0.0.1:11434
OCR_MODEL=qwen3-vl:8b
EXTRACT_MODEL=qwen2.5:14b
```

## Структура
| Файл | Назначение |
|------|------------|
| `pipeline.py` | PDF → OCR (гибрид) → JSON-извлечение → сводка |
| `extract_fields.py` | извлечение полей из текста (для экспериментов) |
| `excel_export.py` | сводка → Excel юристу |
| `sample/` | примеры текстов судебных приказов (тест извлечения) |

## Проверка на ловушке
Два разных должника с одинаковым № дела `2-456(86)/2020` различаются по адресу
(`sample/пример_приказ.txt` vs `sample/пример_приказ2.txt`) — адрес обязательное поле составного ключа.
